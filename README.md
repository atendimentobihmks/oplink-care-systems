# OPLink Care Systems Bio Enzymes — Porque Cuidar é Revolucionar

Hub oficial de links (Blink / Multilink) de alta conversão, canais de atendimento comercial e direcionamento técnico da **Care Systems Bio Enzymes Ltda.** (São João da Boa Vista - SP).

## 🚀 Tecnologias
- **HTML5 Semântico & Acessível**
- **CSS3 Puro** com CSS Custom Properties, Bio-Emerald Theme, Microinterações e Efeitos de Hover
- **JavaScript Vanilla** com GA4 e Meta Pixel CTA click tracking
- **Vite** para desenvolvimento ultra-rápido e build de produção estático
- **Vercel** deploy ready

## 📦 Como rodar localmente

`ash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
`
